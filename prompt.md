1. Project Overview
Students are required to build a Hackathon Management Platform using the MERN Stack.
The application should provide a complete solution for organizing, managing, participating in, and
evaluating hackathons through different user roles.
The project should resemble a real-world software product rather than a basic CRUD application.
Students are encouraged to think like software engineers and product developers while implementing
the project.
2. Problem Statement
Most college hackathons are currently managed using multiple platforms such as:
Google Forms
WhatsApp
Email
Excel Sheets
Google Drive
This makes registration, communication, judging, submissions, and result declaration difficult to
manage.
The objective of this project is to build one centralized platform where every stakeholder can perform
their tasks efficiently.
